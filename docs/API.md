# HTTP and server-action reference

Generated by `npm run docs:api`. Roles are read from the guard each function calls. Every server action re-checks its role on the server; the UI hiding a button is never the control.

## Route handlers (`src/app/api`)

| Route | Methods | Access |
| --- | --- | --- |
| `/api/account/export` | GET | Signed in (ownership checked in the handler) |
| `/api/auth/google/callback` | GET | COLLEGE_ADMIN (verified college) |
| `/api/auth/google` | GET | COLLEGE_ADMIN (verified college) |
| `/api/college/report` | GET | COLLEGE_ADMIN (verified college) |
| `/api/files/:id` | GET | COLLEGE_ADMIN (verified college) |
| `/api/health` | GET | Public (returns only a safe status) |
| `/api/interviews/:id/ics` | GET | Signed in (ownership checked in the handler) |
| `/api/sessions/:id/ics` | GET | Signed in (ownership checked in the handler) |
| `/api/upload` | POST | COLLEGE_ADMIN (verified college) |
